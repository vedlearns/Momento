# Momento Backend Scaffold

Stack: Java 21, Spring Boot 3, Maven, PostgreSQL, Spring Data JPA, Flyway.

This is a folder scaffold, not a runnable backend yet. Generate a real Spring Boot project and replace the placeholder `pom.xml` and application class.

Recommended Spring Initializr dependencies:
- Spring Web
- Spring Security
- Spring Data JPA
- PostgreSQL Driver
- Validation
- Spring Boot Actuator
- Flyway Migration
- Spring Boot Test
- Spring Security Test

Add springdoc-openapi for Swagger UI. Copy the generated Maven wrapper and `.mvn/` directory into this folder.
